# Heart Disease Prediction using Machine Learning

## 📌 Project Overview
This project predicts whether a person is at risk of heart disease using Machine Learning classification algorithms.

## 📂 Dataset
- Framingham Heart Disease Dataset

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Machine Learning Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- Classification Report

## 🎯 Project Outcome
This project compares multiple machine learning models and identifies the model that performs best for heart disease prediction.
